# Interview talking points
Project summary: "I built a defensive threat-hunting and incident-response learning lab using documented hypotheses, synthetic telemetry, a local IOC watchlist, a harmless YARA training rule, and a Python triage utility. I designed a human-approval SOAR workflow as a future extension."

Be ready to explain: threat hunting vs alert monitoring; testable hypotheses; why IOC matches are not proof; YARA limitations; false positives; why containment needs approval; incident timelines; safe API enrichment.

Be transparent about which components you ran locally and which integrations remain design proposals.
