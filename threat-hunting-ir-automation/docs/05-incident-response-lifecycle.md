# Incident response lifecycle
1. Preparation: assets, logging, contacts, approved procedures.
2. Detection and analysis: validate alerts, scope activity, preserve evidence.
3. Containment: proportionate approved actions with business-owner input.
4. Eradication and recovery: follow change and recovery procedures.
5. Post-incident review: root cause, gaps, lessons, detection improvements.
This repository documents a learning workflow; it does not perform enterprise incident response.
